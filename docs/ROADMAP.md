## 历史决策

早期产品是看板与聊天，保留了 Electron IPC、Prisma/SQLite 和 Web 看板实现。Phase 1 的历史实现见[变更记录](../CR-2026-06-16.md)。后续看板 Phase 2—5 已被当前产品规划替代，不作为待办。

项目决定复用 Nexus 的模型调用、Agent 和运行记录，Assistant 处理自身业务与界面。单 Agent 正文处理的当前实现、目标环境状态及历史验证范围见[27](backend-integration/27-接口复核与AI业务调用说明.md)。

已删除旧的能力缺失清单、假设调用路径和待确认开发建议，包括“平台不提供工具循环或 Agent、由 superapp 自行补齐”。这些判断不适用于当前 Nexus；不再保留为可执行要求。历史测试与失败证据仍保留在对应验收记录。

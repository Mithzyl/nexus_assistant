## 5. 有效建议、未知结果、重复提交、页面恢复

- **有效建议**：客户端提交后 worker 领取，`ai_analysis.status=available`，
  建议标题来自模拟模型 JSON，网页显示标题与“模型分析（基于开发/测试数据）”标签。
- **结果不确定**：`/_debug/unknown_once` 让工作流 `outcome_unknown`，建议仍保存，
  `GET /advisories/{id}` 返回 200（不 500），网页显示“模型分析未完成”。
- **重复提交**（`tests/e2e/idempotency_check.py`）：
  - 同一 `Idempotency-Key` 发送两次：同一 `check_id`，第二次 `X-Idempotent-Replay: true`；
  - 数据库共 4 条检查 = 1 条重放 + 3 条不同 key，`commute_internal` 模型运行 0 条；
  - 3 个不同 key 生成 3 个不同检查。
  后端报告的“8 个请求生成 8 条检查”验证的是**不同操作并发成功**，不是同一次操作不重复；
  本轮把两类结果分开记录。
- **页面恢复**：`acceptance_round1_flow.py` 29/29 通过，覆盖关页重开同一 `checkId`、
  检查/建议/模型运行各仍为 1 条；天气更新不改旧建议依据；账号隔离。
  （该脚本原先固定“23:00 到达”，在深夜运行会因窗口关闭失败；改为按当前时间取近未来到达，
  这是测试脚本修正，不是产品改动。）

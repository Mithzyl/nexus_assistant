# 01 技术栈与复用边界

## 1. NexusPilot 的实际依赖（读自仓库，不是设计目标）

| 层 | 实际实现 | 证据 |
|---|---|---|
| 语言 | Python ≥ 3.11 | `apps/api/pyproject.toml` |
| Web 框架 | FastAPI 0.116.1 + uvicorn 0.35.0 | `apps/api/requirements.txt` |
| 数据验证 | Pydantic v2（`pydantic-settings` 2.10.1） | 同上 |
| ORM | SQLAlchemy 2.0.51（asyncio）+ aiomysql 0.3.2 | 同上 |
| 迁移 | Alembic 1.16.4，最新迁移 `20261018_0024` | `apps/api/migrations/versions/` |
| 数据库 | MySQL 8.4（compose 镜像） | `deployments/compose/docker-compose.yml` |
| 对象存储 | MinIO（`minio==7.2.16`） | `apps/api/requirements.txt` |
| 缓存 | **无**。无 Redis / Dragonfly 依赖，compose 无对应服务 | `requirements.txt`、compose 全文 |
| 模型适配 | 独立包 `packages/models`（`nexuspilot_models`），不吃 FastAPI、不连数据库 | `packages/models/src/nexuspilot_models/` |
| Agent 执行 | `features/agent_runtime/`，工作流执行由进程内 asyncio 任务持有 | `services/workflow_execution_tasks.py` |
| 流式 | SSE，事件持久化在 `llm_agent_workflow_events`，按 `event_sequence` 递增 | `models/agent_workflow.py:179`、`services/workflow_query_service.py:205` |
| 前端 | Next 16.3.8 + React 19.2.6 + TypeScript 5.9.3；样式为原生 CSS，无 Tailwind 依赖 | `apps/web/package.json` |
| 身份 | 部署级 `X-API-Key` + 本地密码 + 不透明 Cookie 会话 | `core/security.py`、`features/identity/` |

> 版本结论：NexusPilot 没有缓存层，也没有消息队列。任何依赖"共享临时状态"的设计（登录失败计数、工具调用去重、SSE 广播）都必须先落在 MySQL 上，或者明确引入新基础设施——后者不属于本次范围。

## 2. Personal Assistant 的实际状态

Personal Assistant 在本仓库中**不存在**。本次交付的 `services/assistant-api/` 是新建脚手架，用于验证接口契约与隔离规则，不是生产实现。

| 层 | 脚手架现状 | 生产目标 |
|---|---|---|
| 语言/框架 | FastAPI 0.161.1 | 与 NexusPilot 对齐到 0.116.1（见 06 待对齐） |
| ORM | SQLAlchemy 2.1.6 + aiosqlite | MySQL 8.4 + aiomysql，与 NexusPilot 同版本 |
| 迁移 | 无，`allow_schema_create` 直接 `create_all` | Alembic 独立库 `personal_assistant` |
| 数据库 | SQLite（测试内存库） | 独立 database，独立受限账号 |
| 缓存 | 无 | 第一阶段不引入 |
| 对象存储 | 不使用 | 只引用 NexusPilot 的 file id，不直连 MinIO |
| 模型调用 | 无适配器 | 仅调用 NexusPilot 应用 API |
| 前端 | 无 | 复用 `apps/web` 的组件规范与设计 token，不共享构建产物 |

### 3.3 明确不共享

- 不共享 ORM 模型：PA 不 import `nexuspilot_api.models`。
- 不共享数据库连接：PA 有独立 database 与独立账号。
- 不共享 Provider 适配器或模型凭据；当前上游要求的工作流 `role_bindings` 仅作为
  assistant-api 的服务端配置下发，客户端不可见、不可改。
- 不共享登录态：PA 用户不写 `users` 之外任何 NexusPilot 表；PA 也不校验 NexusPilot Cookie。
- 不共享对象存储凭据：PA 只能通过 API 拿到已授权文件的内容或签名地址。

## 4. 与提示词技术表的差异（必须显式说明）

| 提示词中的项 | 仓库现实 | 处理 |
|---|---|---|
| Redis / Dragonfly | 不存在 | 第一阶段不引入；幂等靠 MySQL 唯一约束 |
| Agent Runtime 作为独立服务 | 是 API 进程内的 asyncio 任务，进程重启不恢复 | 不宣称"断点续跑"；跨进程恢复仍需 Phase 10 |
| Memory Service 可调用 | 表与检索存在，但已暂停接入 `/responses` | 只做显式 API 召回，不自动注入 |
| Workflow 状态在 NexusPilot | 是，`llm_agent_workflow_executions` | 直接复用 |
| MinIO 由 NexusPilot 管理 | 是，`user_files` + `llm_artifacts` | PA 只存引用 id |
| 工作流 SSE 可断线恢复 | 已提交事件可回放；运行中断线不重连推送 | 恢复靠 `Last-Event-ID` 重订阅，不靠推送 |

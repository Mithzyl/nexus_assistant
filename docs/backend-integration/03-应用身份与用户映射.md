# 03 应用身份与用户映射（当前实现）

更新时间：2026-10-23。此前 `pilot_principals` + `/api/v1/app/principals/resolve` 的方案
没有进入当前 NexusPilot 代码，已由下面的实际实现替代。

## 1. 三条禁令

1. Personal Assistant 用户不注册、不登录 NexusPilot。
2. 客户端不得提交 `user_id` / `principal_id` / 平台用户 ID；身份只来自 PA 会话令牌。
3. 不同应用、不同本地用户不能复用同一平台所有者。

## 2. 当前 NexusPilot 身份模型

源码：`features/identity/routers/application_runs.py`、
`features/identity/services/application_identity.py`、
`features/identity/models/applications.py`。

| 表 | 作用 | 关键约束 |
|---|---|---|
| `applications` | 已启用的应用 | `application_id` 主键 |
| `application_user_mappings` | `(application_id, external_user_id)` → 平台用户 | `UNIQUE(application_id, external_user_id)`；每个平台用户只映射一次 |
| `run_application_context` | 把 Run 固定到 mapping 和工具版本 | `run_id` 主键；mapping 必须匹配 |

认证与开户在同一个应用请求内完成：

```text
Authorization: Bearer <application credential>
X-Application-Id: personal_assistant
X-External-User-Id: <PA users.user_id>
```

1. NexusPilot 校验应用凭据和 `X-Application-Id`。
2. 以 `X-External-User-Id` 查 mapping；不存在时在认证事务内创建平台用户和 mapping。
3. 把平台用户写入请求上下文，后续资源归属校验复用既有 `users.user_id` 链路。
4. 请求体没有身份字段；`user_id` 等字段会被 `extra=forbid` 拒绝。

**不存在** `/api/v1/app/principals/resolve`，也**不返回** principal id。PA 不需要、
不应该再维护 `nexus_identity_links` 作为身份前置条件。

## 3. PA 侧当前做法

- 登录/登出/`/me` 完全由 PA 的 `users`、`user_sessions` 负责；令牌只存 SHA-256 摘要。
- 每次提交/读取/订阅/取消前，从本地会话得到 `user.user_id`，仅在服务端请求头写入
  `X-External-User-Id`；浏览器和模型都看不到这个断言。
- `nexus_runs.nexus_principal_id` 改为可空；新运行不写 principal。
  历史行保留原值，不影响当前读取。
- 本地 `(user_id, idempotency_key)` 唯一约束阻止重复提交创建第二条 App 请求。
- 跨用户读取、订阅、取消先查本地 `nexus_runs.user_id`，不命中直接 404，不触达上游。

## 4. 失败与停用

| 情况 | 当前结果 |
|---|---|
| 应用凭据无效/缺失 | 上游 401 → PA 502 `nexus_application_unauthenticated` |
| 外部用户断言缺失 | 上游 422 → PA 502 `nexus_invalid_request` |
| mapping/用户被停用 | 上游 404 → PA 404 `nexus_resource_not_found` |
| 停用应用 | 上游认证失败；PA 不自动重试，记录 `failed` |
| 创建 Run 超时 | PA 记录 `unknown`，不重试 |

## 5. 数据库

当前使用 SQLite + SQLAlchemy/aiosqlite。`nexus_runs.nexus_principal_id` 在 ORM
模型中是可空字段；空库通过 `scripts/migrate_sqlite.py init` 建立，既有库通过
`scripts/migrate_sqlite.py upgrade` 增量升级。不修改 NexusPilot 表，不做跨库查询。

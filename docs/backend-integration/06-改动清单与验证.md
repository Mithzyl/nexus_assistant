### 6.2.1 真实 HTTP 与契约漂移（2026-10-23 追加）

单元测试的 `httpx.MockTransport` 不经过网络，无法证明流式与进程启动。补充两项：

| 脚本 | 结果 | 覆盖 |
|---|---|---|
| `scripts/e2e_check.py` | `15/15 checks passed` | 两个进程真实 HTTP：登录、鉴权、交入、分块 SSE（跨度 0.28s、首帧 0.10s）、`Last-Event-ID` 续传、重复提交重放、取消、三个业务工具 + 回执、记忆召回、9 次上游调用零身份字段 |
| `scripts/check_contract.py` | `contract ok: 7 interfaces, 9 endpoint constants` | `v3-kit/source/src/api/contract.ts` 与 OpenAPI 双向字段比对、必填字段不得在前端标可选、端点常量必须命中已注册路由 |

前端 `tsc --noEmit` 通过。

同时修掉一个真实缺陷：`httpx` 默认继承 `HTTP_PROXY`，本机设置代理后 PA 调 NexusPilot 的请求（含 `127.0.0.1`）被代理拦截并返回 404。`NexusPilotClient` 已改为 `trust_env=False` —— 这属于生产配置风险，不只是测试问题。

### 6.3 这些结果**不**代表什么

- 不代表与真实 NexusPilot 联调通过。上游是 `httpx.MockTransport`。
- 不代表 MySQL / MinIO / Alembic 路径验证过。测试用 SQLite 内存库。
- 不代表性能、并发、限流可用。没有压测。
- 不代表原生端或前端可用。本轮只做后端。

# 12 设备内容来源与同步契约（PA 后端）

更新时间：2026-10-24。本文只定义 PA 数据库侧接口；第一版不对系统日历、提醒事项或备忘录写回。

## 1. 所有权与三条独立开关

| 概念 | 含义 |
|---|---|
| `sync_enabled` | 是否允许设备继续上传新批次；关闭后已有副本保留 |
| `assistant_enabled` | 是否允许云助手工具读取该来源；关闭后用户仍可在 App 查询 |
| `upload_fields` | 允许上传并保存的字段子集；撤权会清理旧副本中的字段 |

三者互不替代。`scope_keys` 是用户选中的日历/提醒列表/笔记范围；移除 scope 只停用范围，
不会把本次未上传的记录当成删除。

## 2. 来源管理

```text
POST   /api/v1/data-sources
GET    /api/v1/data-sources
GET    /api/v1/data-sources/{source_id}
PATCH  /api/v1/data-sources/{source_id}
DELETE /api/v1/data-sources/{source_id}/items
DELETE /api/v1/data-sources/{source_id}
```

创建示例：

```json
{
  "source_type": "calendar",
  "device_id": "iphone-...",
  "display_name": "iPhone 日历",
  "scope_keys": ["calendar-home"],
  "upload_fields": ["title", "start", "end", "location"],
  "assistant_enabled": false
}
```

`source_type`：`calendar`、`reminders`、`notes`。
字段白名单：

- calendar：`title/start/end/location/notes/status`
- reminders：`title/due/notes/status`
- notes：`title/body/tags`

`title` 与对应类型必要时间字段必须授权。PATCH 的五个字段可独立更新：`display_name`、
`sync_enabled`、`assistant_enabled`、`upload_fields`、`scope_keys`。

删除语义：

- `DELETE /items`：删除已上传副本，保留来源和授权，后续可重新同步；
- `DELETE /data-sources/{id}`：删除来源及全部副本；
- `sync_enabled=false`：只停止后续上传，不删除已有副本；
- `assistant_enabled=false`：助手不再读取，但 App 查询仍可读取。

## 3. 上传批次

```text
POST /api/v1/data-sources/{source_id}/sync
```

```json
{
  "batch_id": "device-batch-uuid",
  "items": [
    {
      "external_id": "EKEvent:...",
      "scope_key": "calendar-home",
      "version": 3,
      "updated_at": "2026-10-24T01:00:00Z",
      "title": "牙医复诊",
      "starts_at": "2026-10-25T01:00:00Z",
      "ends_at": "2026-10-25T02:00:00Z",
      "location": "口腔医院"
    }
  ],
  "removed_external_ids": ["EKEvent:deleted"]
}
```

规则：

- `batch_id` 在来源内幂等；重复上传返回首次统计，不重复写入。
- `(source_id, kind, external_id)` 唯一；版本较小或同版本更新较旧视为 unchanged。
- `scope_key` 必须是当前 active 范围，否则 422。
- 只有 `upload_fields` 内的字段可出现在同步项中；未授权字段 422。
- `removed_external_ids` 是**显式删除**；未出现在本批次的记录不会删除。
- 范围收窄：PATCH `scope_keys` 将缺失 scope 置为 inactive，旧副本保留但 App/助手均不可见。
- 范围重新加入：该 scope 获得新的 `activated_at`；旧副本在重新同步前不可见，避免使用过期数据。
- 来源或 scope 删除不依赖“本次未出现即删除”。

## 4. 内容查询（App 使用）

```text
GET /api/v1/content?kind=note&query=...&limit=50&offset=0
GET /api/v1/content/{item_id}
```

只返回当前 PA 用户、未删除、当前 active scope 且在该 scope 激活后同步过的记录。
`assistant_enabled` 不影响 App 自己的内容查询。

## 5. 工具适配

复用当前三个只读工具，不新增 Agent 循环：

- `personal_assistant.list_calendar_events`：原生 `schedules` + authorized `calendar_event`；
- `personal_assistant.list_tasks`：原生 `tasks` + authorized `reminder`；
- `personal_assistant.search_notes`：原生 `notes` + authorized `note`。

工具额外受 `assistant_enabled=true`、active scope、未删除、字段授权约束。结果仍为
`BusinessReadResult`（`items` ≤ 20，`next_cursor`）。

## 6. 当前边界

- 不写回 EventKit、不勾选提醒事项、不修改 Apple 备忘录。
- 不做双向冲突合并；服务器按 version + source_updated_at 拒绝旧记录。
- 不做历史版本保留；字段撤权会清理旧副本对应字段。
- 不提供跨用户共享或公开链接。

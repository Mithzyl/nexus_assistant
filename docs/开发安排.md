## 2. 状态依据

| 状态 | 本次采用的依据 |
|---|---|
| 已完成并验证 | 本轮没有把任何规划任务标成此状态。 |
| 已开发未验证完整 | 代码中确实存在对应组件或能力，但缺少规划要求的完整流程或验证记录。 |
| 仅供演示 | 页面明确处于演示模式，数据来自 `lib/mobile/demo.ts` 或 localStorage。 |
| 尚未开发 | 当前代码与接口中找不到对应实现。 |
| 无法确认 | 依赖外部环境或分支、本轮无法只读确认的情况；本文未使用该状态。 |

补充说明：

- 本表没有把“页面能点开”当作任务完成，也没有把历史测试记录当作本轮验证。
- 模块一、模块二的“尚未开发”是按当前 `main` 工作区代码判断；代码基线为 `26095a8b`，其他已核实分支提交与未合入范围见落地对照中的版本说明，不能混作 main 已完成。
- 任务项与原文逐字对应，没有自行拆成更细的子任务，也没有新增原文没有的模块。

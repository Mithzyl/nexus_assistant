## 6. 查找规则

1. 想知道“产品现在要求什么” → 只看第 1 节。
2. 想知道“某条要求现在做到哪” → 第 2 节对应文档，最终以第 1 节原文为准。
3. 想知道“当时怎么测的” → 第 3 节，注意日期与测试范围。
4. 想知道“以前怎么规划” → 第 4 节，不得把其中内容当作现行要求。

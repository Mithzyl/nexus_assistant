## 1. 已保留的真实能力

- 登录、会话续期、退出、账号隔离。
- 问助手真实提交、历史、执行状态、取消、失败与恢复；没有把答案文本推断成事项保存。
- 通勤计划、检查、建议、后台状态四类文案；上一轮 `server_time` 老化、失败降级、可见性暂停与旧响应保护未改。
- 内容来源、上传副本、Bark 和隐私说明。
- 暖白/雾蓝变量、深色模式、移动断点、底部安全区与软键盘处理。

## 2. 本轮页面与交互

### 导航与安装

- 底栏改为 `今天 / 事项 / 问助手 / 我的`，地址仍为 `/today`、`/matters`、`/ask`、`/me`。
- 新增 `app/manifest.ts`、192/512 图标、Apple touch icon；`start_url=/today`、`standalone`、主题色与背景色。没有 service worker，因此不缓存账号私密响应；也没有离线写入或关闭网页后的提醒。

### 今天

- 日期、书卷感概览；概览中的安排数量来自当前本机预览，不是固定示例。
- 仅在预览日程余量不足时显示琥珀色左边框变化卡；点击打开底部面板，提供三个调整方案。关闭不提交。
- 今日时间线按时间排序展示预览日程和今日到期预览提醒；明确标注“应用内预览”，提醒关闭网页后不送达。
- 真实通勤卡继续独立显示；不把后台在线、检查完成、建议可用混成一种状态。
- 普通模式不出现预览时间线/变化卡；没有把演示数据混入真实空状态。

### 事项

- 三组：正在推进、等待外部反馈、已完成／归档。
- 列表卡只保留标题、最新进展、下一步动作与时间。
- 详情四块：目标与背景、已确定安排、待处理清单、跟进记录（可折叠）。
- 本机可纠正标题/目标/下一步、修改预览日程时间地点、勾选待办、补充进展、停止跟进并归档、彻底删除本机预览、撤回上次预览修改。
- 日程状态只显示“应用内预览 · 未写入服务器”或“未写入 iPhone”，没有虚假回写。
- 数据按账号保存到 `localStorage`；删除后重开不恢复；关闭预览显示真实空状态。

### 问助手

- 保留原有真实问答与历史，没有新增客户端解析或“从回答猜保存成功”。
- **未实现待确认变更卡/确认落库**：后端没有结构化变更字段或事项接口，前端不伪造。实验室只展示计划接续的独立预览，不冒充服务器回复。

### 我的 / 实验室

- 新增“数据与同步”区：内置日程（未接通/预览）、iOS 客户端（未连接）、内容副本最近同步（真实 `data-sources.last_sync_at`）；明确上传副本不等于写回系统日历。
- 新增 `/me/lab`：计划接续预览入口、旧版退款/票据/愿望/出门清单演示、演示模式开关、重置预览。旧消费演示不再进入主“事项”列表和“今天”。
- 个人记忆支持修改、停用与可发现的“删除这条经验”按钮；仍明确是演示，不称为助手永久记住。

## 3. 字段与真实接口

本机预览使用独立类型 `apps/web/lib/mobile/work-plan.ts`：

- `WorkMatter`: id/title/goal/status/progress/nextAction/nextAt/schedules/todos/history/stopped
- `WorkSchedule`: id/title/startsAt/endsAt/location/source/syncStatus
- `WorkTodo`: id/title/dueAt/reminderAt/done
- `WorkHistory`: id/at/text

这些**不是**后端已存在字段。没有新增 `/api/pa` 路径，没有把 DemoProvider 的事务对象当作接口，也没有调用 `/sync/ios/*` 或 `/commute/estimate`。

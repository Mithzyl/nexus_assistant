# 资料与同步说明

> 更新：2026-11-09，依据实际 backend/dev 模型/路由与已完成本机启用记录。本次仅同步文档，不访问设备或执行同步。

## 现有接口与数据

| 范围 | 实现 | 使用限制 |
| --- | --- | --- |
| 资料来源和副本 | `routers/data_sources.py`、`models/content.py` | 保留来源、字段授权、范围和批次；设备副本不等于设备写回 |
| iOS 快照与待写入 | `routers/sync_ios.py` 下的 `/api/v1/sync/ios/snapshot`、`pending-actions` 及关联路由 | 已有后端入口，不能继续描述为未实现；设备实际落库与确认需独立验收 |
| 应用内日程 | `ScheduleEvent`、`routers/records.py` | 支持独立创建/修改/取消及事项关联；与设备导入记录区分 |
| 应用内提醒 | `Reminder`、`MatterTodo` | 保留提醒时间、关联对象、source 和 sync_status；保存不代表已发通知 |
| 路线与地点 | `/api/v1/commute/estimate`、`commute_estimate.py`、共用地点服务 | 路线依赖目标环境配置；不凭历史或 mock 结果宣称实时路线有效 |
| 日程冲突 | `services/matter_conflicts.py` | 已有冲突计算；具体时间范围、余量、候选方案和页面反馈以业务实现及验收为准 |

`source`、`sync_status` 是记录来源和同步进度，不能用来源批次的 `last_sync_status` 替代。规划中的状态名称与接口实际枚举应在客户端适配时核对，不因字段存在就认定设备同步完成。

## AI 读取与执行

Assistant 选择当前用户和事项相关资料，保留用户原文、AI 生成内容与后端事实的区别。Nexus 的单 Agent 接收模型正文处理结果；业务回调只返回当前用户允许使用的必要字段，凭据和执行身份由服务端管理。

协议与本次证据见[27](backend-integration/27-接口复核与AI业务调用说明.md)，设备副本上传契约见[12](backend-integration/12-设备内容同步契约.md)，事项、同步和测算的既有实现记录见[17](backend-integration/17-工作安排与计划接续-后端实现与网页接入.md)。这些记录不代表本次已进行真机验收。

## 业务记忆归属

Assistant 自己保存记忆、原文、模型改写和修订来源；当前输入先检索一次，必要内容交给同一 Nexus Agent 使用。模型只提出操作，Assistant 校验账号、版本和原文后执行；不自动写 Nexus 平台记忆。通勤、事项、日程默认共用本账号记忆，来源事项不是使用限制。遗忘撤回自动使用但保留本人历史及原有来源，物理清除和跨应用共享不属于当前实现。迁移保留原编号和版本，不用任务快照替代完整记忆库，见 [05](backend-integration/05-Agent-工具-记忆运行流程.md)。

# 页面与交互说明

> 更新：2026-11-09。页面要求以[三阶段规划](产品规划-工作安排与计划接续.md)为准，状态汇总见[落地对照](最新规划落地对照-现有能力与差距.md)。本次仅同步文档，不修改风格或页面代码，不运行浏览器。


记忆来源仅在后端校验和内部保存，不作为新增前端来源展示或入口的要求，也不默认把记忆全文放进回答。用户询问、需要澄清歧义或解释重要安排时，由 AI 决定是否简短说明，确需时可用卡片；用户只要文字则不补卡。本次没有修改前端页面或组件。

## 已完成并移出待办

记忆管理不再请求不存在的 instructions 接口或提供未支持的共享操作。历史弹层区分当前/修改前、原话/助手整理和记录时间，固定标题/关闭并恢复焦点。日程详情将未规划路线作为可选动作，不再同时突出出发地/交通方式/耗时待填；重复提醒、内部占位和误称待办提醒已修复。

后端已将真实秒数转换为带单位文本；提醒偏移 -900 对应提前15分钟，数据库值不变。该格式修改加载后未新增真实模型或浏览器验收，不将语法/启动核对写成展示通过。

## 接入要求与待验收

消费 outcome、answer、pending_context.cards；中间 JSON 不作为用户回答。卡片引用真实结果，不自行执行业务。用户原文、AI 整理和后续纠正/回答须保持区别及关联。

后端支持五种交通方式，Web 通勤/路线选择目前只有三种，仍需补齐自行车与电动车。不把“已有地图组件”误写为尚无地图，也不据此宣称所有选点和路线场景已验收。

全局语音/截图/链接、下一步行动、简报复盘和模板尚未完整交付。窄屏、长文本、键盘、跨天恢复、iOS 实际同步及目标浏览器通知仍按相应版本独立验收。2026-10-26 的固定确认按钮规则仅作历史参考，当前明确用户意图按现行规划执行。
